How it works

1. First request → server creates a session, responds with Set-Cookie: session_id=<id>.

2. Browser stores the cookie and sends it on every subsequent request.

3. Server calls SessionManager::get(id) — if the session exists and is within the 30-minute TTL, no new session is created.

4. Click Clear cookie to delete it; the next request will generate a brand-new session.
