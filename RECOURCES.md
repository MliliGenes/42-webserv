## Structure of HTTP Requests and Responses

- **RFC 7230**
  - Link: [RFC 7230](https://datatracker.ietf.org/doc/html/rfc7230)
  - Description: Specification for the message syntax and routing of HTTP/1.1.

- **RFC 7231**
  - Link: [RFC 7231](https://datatracker.ietf.org/doc/html/rfc7231)
  - Description: Focuses on the semantics of HTTP/1.1, including response codes and content types.

- **RFC 9110**
  - Link: [RFC 9110](https://datatracker.ietf.org/doc/html/rfc9110)
  - Description: Updated semantics associated with the HTTP protocol, incorporating changes from prior RFCs.
