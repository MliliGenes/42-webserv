⚙ socket()
Creates the raw TCP socket file descriptor
socket()

SOCK_STREAM — reliable TCP byte stream

int fd = socket(AF_INET, SOCK_STREAM, 0);

🔧 setsockopt()
Avoids "Address already in use" on restart
setsockopt()
SOL_SOCKET — socket-level option
SO_REUSEADDR — reuse TIME_WAIT port immediately
opt=1 — enable the option
→ critical for server restarts
int opt = 1;
setsockopt(fd, SOL_SOCKET, SO_REUSEADDR,
            &opt, sizeof(opt));

Makes the fd non-blocking so poll() never hangs

F_SETFL
O_NONBLOCK — OR in non-blocking flag
→ recv/send return EAGAIN instead of blocking

  fcntl(fd, F_GETFL, 0) | O_NONBLOCK);

[02]
The Poll Loop
run() — main event loop
🔄 poll() — Multiplexed I/O
Single thread watching all fds simultaneously. Timeout = 100ms to run housekeeping.
int n = poll(&_pollfds[0], _pollfds.size(), 100);
// n == 0 → timeout, run _check_timeouts / _compact_pollfds
// n > 0 → iterate pollfds, check .revents
// n < 0 → error (EINTR from signal → continue)
POLLIN
Data is ready to read from this fd without blocking
→ call recv() / accept() / read()
POLLOUT
Write buffer has space — send() won't block
→ call send() / write()
POLLHUP
Remote side closed/hung up the connection
→ _close_client()
POLLERR
Error condition on the fd (pipe broken, etc.)
→ _close_client()
POLLHUP on CGI pipe
CGI process closed its write end — all output is done
→ _handle_cgi_event() drains last bytes
fd = -1
Slot is invalidated (closed fd). poll() skips it.
→ _compact_pollfds() removes it
🗂 FD Registry — Three Maps
Every fd belongs to exactly one category. The loop checks maps to route events correctly.
Map Key Value Purpose
_listeners socket fd ServerConfig index Passive sockets waiting for connections. On POLLIN → accept(). Knows which virtual host config owns the fd.
_clients client fd Client* (heap) Active client connections. Holds parser state, response buffer, file stream, CGI job. Cleaned up on disconnect.
_cgi_fds pipe fd CgiFdInfo {client_fd, is_stdin} stdin/stdout pipes to child CGI process. Routes data back to the owning client. Removed once pipe is drained/closed.

⚗ CGI Pipe Architecture
Two pipes bridge the HTTP client and the CGI subprocess. Both are non-blocking and tracked in _cgi_fds.
spawn()
cgihandler
fork() + exec(). Creates pipe pair: in_fd (stdin of child), out_fd (stdout of child)
O_NONBLOCK on both ends in_fd → POLLOUT if body exists out_fd → POLLIN | POLLHUP
write()
stdin pipe
On POLLOUT: write() chunks of request body (4096B) into in_fd. Track body_sent offset. Close in_fd when done (signals EOF to child).
4096B chunks body_sent += w close on complete
read()
stdout pipe
On POLLIN: read() appends to cgi.raw buffer. On POLLHUP/r≤0: pipe is done, invalidate fd. waitpid() with WNOHANG to reap child.
raw.append(buf, r) WNOHANG parseOutput() on close

[06]
FD Management & Cleanup
invalidate · compact · safe_close · timeouts
🗑 Two-Phase FD Removal
Never erase from _pollfds while iterating — mark first, sweep later
phase 1
invalidate
Set pollfds[i].fd = -1. poll() ignores negative fds automatically.
phase 2
compact
Swap-with-back + pop_back on every fd<0 entry. Called after each poll iteration.
// compact: O(n), no allocations
while (i < _pollfds.size()) {
  if (_pollfds[i].fd < 0) {
    _pollfds[i] = _pollfds.back();
    _pollfds.pop_back();
    continue; // re-check same index
  }
  ++i;
}
🔒 safe_close()
Closes fd and resets to -1 in one atomic guard step
static void safe_close(int& fd) {
  if (fd >= 0) {
    close(fd);
    fd = -1; // guard double-close
  }
}
Prevents double-close bugs (UB + potential fd reuse vulnerability)
⏱ Timeout Housekeeping
